# 左边栏「看板」双核心重构评审与任务走查记录（2026-11-13）

定型：老项目改造 · 改流程与加新功能 · 阶段：已完成

## 1. 现状诊断与重构目标

- **旧版痛点**（见 `before/board-1440.png`、`before/board-1084.png`）：
  1. 五页签（`Overview / Board / Schedule / Ideas / Daily`）围绕「手动预估工时（`0h / 6h`）+ 14 天负荷柱 + 手打习惯打卡」设计，与多产品、多 AI 会话并行推进的真实工作流脱节，长期处于 `0% / 0h` 空转。
  2. 176px 纵向 `Topics` 二级侧栏叠加在 240px 主侧栏右侧，形成双侧栏挤压主画布。
  3. 真正卡住推进的「待拍板确认项」（产品卡 `等你决定`、等待回复的会话）与「每天实际做成了什么」（跨仓提交、上线、已完成待办）分散在各仓与脚本里，看板里既看不到也导不出。
- **重构目标**（用户明确指令）：
  - 将左边栏「看板」彻底重构为两大零手填负担的核心模块：
    1. **待确认与待定执行的任务待办**（`PendingQueuePanel`）：自动归集工作台产品卡 `等你决定` / `没收尾的`、`STATUS.md` 近期里程碑与实时 `waiting` 会话；支持单行快速录入、一键 `确认转执行`、一键 `派会话` / `打开会话`、一键 `完成并记入今日清单`。
    2. **每日任务实现简述清单**（`DailyDigestPanel`）：按日倒序自动聚合已完成待办、手记补记、`workbench/data/releases.jsonl` 与多仓近 21 天 `git log`；支持行内编辑润色、隐藏杂项与一键复制 Markdown 日报。
